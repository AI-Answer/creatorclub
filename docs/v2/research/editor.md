# What the embedded editor can do today (static code audit, 2026-10-29; file:line in the agent's report)

Exists: move, trim, split, delete, copy/paste; per-clip speed 0.25–4x, volume, fades, denoise and normalize (export only), transform, colour, mirror; manual zooms 1–8x with short ramps; one global caption style; six static element types (text, rectangle, ellipse, arrow, highlight, blur); music import with gain; four aspect presets, five layouts (Creator, Full, PiP, Side-by-side, Spotlight); automations (remove pauses, filler review, close gaps, normalize); export MP4/WebM/WAV/SRT/TXT/MD/JSON; transcript delete ripple-cuts every track.
Does NOT exist: motion graphics (no animated titles, lower thirds, kinetic text, charts; elements are static and only shown or hidden by time window), transitions, clip keyframes, crop, speed ramps, auto zoom (zooms are manual; cursor points come from a Borumi import), caption presets or animation, music ducking, device frames, any style or template library. "Style video" only proposes a layout plus three plain text slates per scene, with one before/after still.
Preview vs export differ: rectangles and ellipses are outlined in preview but solid in export, arrows differ. The text rasterizer is a macOS-only Swift helper.
Preview is DOM (one video element per active clip plus CSS), not canvas or ffmpeg. The proxy preview is never generated. A cheap quick preview of a style or auto-cut exists as a pattern (CutPlayback plus the pure applyOperations).

Timeline defects: about one 70px row visible at the default 200px height (the five role rows always exist, empty or not); effect rows (elements, captions, zooms) are click-only, with no drag, resize or snap; ripple only affects Delete on the same track; screen, camera and audio of one take are separate, unlinked clips; zoom uses a fixed px/sec and does not anchor the scroll, so the view jumps; the ruler is text only, with no ticks or frame precision; no user markers; blade clicks and media-library drops do not snap; clips can overlap on a row; the playhead always re-pages and cannot be turned off; one tiny thumbnail per clip and a coarse waveform; any background save cancels an in-flight drag; the toolbar's Duplicate and Delete are hidden by CSS; four stylesheets override each other.

Companion chats today: (1) the editor chat ("Ask Claude", Edit only) spawns local claude with a restricted toolset (17 editing tools: update_clip, split_clip, delete_clips, add_clips, set_captions, set_elements, set_zooms, update_canvas, set_cursor, trim_timeline, update_scenes…) and applies one transaction per request with undo; it knows nothing of the plan, package or voice. (2) the Board chat is one-shot JSON through the club's claude/codex runner and only suggests hooks, titles, notes and scenes; it knows the voice, idea, package and outline. One docked panel for all steps is feasible: mount it in Workspace, lift selection and playhead out of App, pick the toolset by tab, one runner and one conversation per video, and add editor tools (apply style, auto-cut, add title).

Embedded Edit shows 51 fixed controls at first paint (+3 per scene), plus 20–40 fields once a clip is clicked. The Settings gear is hidden in the embed, so the SceneForge Settings dialog is unreachable.
