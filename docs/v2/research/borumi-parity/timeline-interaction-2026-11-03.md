## Implemented model

Creator Compiler uses explicit link groups for each take slice, source-time caption projection, a single edit on gesture release, insertion/reorder by default, and Alt for a deliberate gap/free placement (trim uses Alt to disable ripple). It permits visual layering through explicit layer moves while preventing same-row overlap. All editor surfaces share these primitives. Snap targets include the playhead, clip edges and scene bounds and honor the magnet. Escape cancels previews. Existing scene ranges remain nonoverlapping; take provenance is retained when pieces reorder, and whole-scene reorder remains the existing separate scene gesture.

Captions are split against narration source ranges before source reordering, then projected back into each destination piece. The timeline renders words inside their owning clip, including the drag preview; a clip with no words gets no empty caption band. Copy/paste includes linked pieces and their source captions, with independent links for the copy.

The false conflict came from `automatic-captions` storage events being treated like external edits despite already having that source marker. The editor now validates a captions-only delta and rebases current, undo and redo snapshots in source time under the save queue. An HTTP 409 that races ahead of SSE follows the same validated merge/retry path. Genuine other-content changes preserve the draft and show a calm nonmodal notice.

The black preview had two contributing paths: ordinary free moves could leave holes, and an exact end-boundary playhead selects no half-open clip range. Default insertion prevents newly orphaned gaps; source bounds clamp linked trims; the stage shows the final frame when transport rests exactly on the end boundary. Deliberately empty timeline time stays empty.

Waveform extraction retains absolute peaks; a fixed -72 to 0 dBFS display range makes quiet speech readable without per-source normalization. Video with unknown legacy audio metadata is probed rather than discarded. Audio-bearing camera/video clips subscribe to the same waveform cache.

## Colours and control rows

Borumi picks a segment's fill in `up()` (formatted main chunk around 39068): `bg-yellow-400` for control layers, `bg-purple-400` for overlays, `bg-blue-400` for video, `bg-green-400` for audio alone. Its stylesheet (`index-DXJH5HZm.css`) defines the colour scale twice, and the dark block runs it backwards (dark `blue-400` is light `blue-600`). The same class is therefore `hsl(213 94% 68%)` in light and `hsl(221 83% 53%)` in dark. The control yellow is `hsl(43 96% 56%)` in light and `hsl(32 95% 44%)` in dark, the orange the creator noticed. Creator Compiler had used the dark blue in both themes, so its light timeline looked much darker than Borumi's. A take's waveform uses `var(--color-primary)`, which the stylesheet never defines, at layer opacity 40% (80% on hover); it renders as black at 40%. The caption pill is `bg-background/50` with `text-primary`. Selection is `ring-2 ring-offset-1 ring-blue-500`. Sampled renders match: in dark, waveform `#173b8d`, pill `#1a367a` and layout `#dc7607`; in light, waveform `#3b6396` and layout `#fabd24`.

Control layers (`o9`/`a9`/… around 33630–34010) are layout, screen zoom, camera zoom, blur, highlight, captions, cursor and music, stacked under the content layers in that order. Each lane is 32 pixels (`mj`), and an empty control lane is hidden (`L9`). Captions, cursor and music lanes show only while their panel is open. Clicking a segment selects it, seeks, and opens its panel (Layout, Zoom, Clip, Elements or Music, around 43760). Hovering an empty part of a control lane shows a `+ Layout`-style ghost of a tenth of the visible duration inside the free room (`V0`/`IF`/`NV`, around 36440 and 40818); mouse-down and drag set its length, and release creates it. Borumi then asks for a layout in a modal. Layout segments render centred, with the layout's icon and "Layout" when wider than 70 pixels (`Vz`). The Layout panel (`tq`, around 54400) applies a choice to the selected layout segments, else to those under the playhead (`Fj`), else as `update_for_range` at the playhead.

Creator Compiler stores these as `Project.layouts` stretches (`shared/layouts.ts`). The preview places camera and screen clips by the stretch at the current time. Export cuts clips at stretch edges with `bakeLayouts`, using `effectTiming` like a split, so fades and sound stay continuous. Ripple cuts, openings, deletes, accepted takes and scene reorders move stretches with the footage. The panel follows Borumi's selected → under-playhead → new-from-playhead order, and a new stretch runs to the next change. A click or drag on the empty Layout row creates a stretch in the layout the clips have outside stretches, then selects it and opens the Layout panel in place of Borumi's modal. Colours are the `--kind-*` tokens, themed in `club/ui/tokens.css`. Captions stay visible (they carry typed caption text here, not a style control), and there is no music-panel gating.
