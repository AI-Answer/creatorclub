## Sections

### Why this matters (0:45 – 1:45)
- Say: phone channels get huge views on "hidden features" because everyone owns the thing and uses a sliver of it. AI tools are the same. Use the idea's proof: iPhone versions got 710K and 530K views from one small channel. Don't add other numbers.
- Analogy: a car dashboard where you only ever use the radio and the wipers. The other buttons are there and nobody told you. Or a kitchen drawer gadget you thought was junk.
- Name the false belief (Ed): "I need to be super technical." These are settings and menus, not code.
- Reassurance: "Even if you've never changed a setting, you can follow this. Let's get into it."
- Show: the phone-style hidden-features idea can be a quick cut to a phone settings page, then the AI tool's home screen.
- Look for: keep it under a minute. Don't turn it into a lecture.

### Level 1: one-click features (1:45 – 4:00)
- Say: what a hidden feature is, with the car dashboard comparison. Then go through two or three features that take one click or one sentence. Explain each in plain words, say what it saves, and say what it costs, if anything.
- Show: open the tool's docs, then do each feature live. Say the prompt aloud as it's typed.
- Look for: the before and after. Did it do in one step what usually takes several? Say honestly if one feature is smaller than expected.

### Level 2: a workflow that changes how you work (4:00 – 7:00)
- Say: this is where features stack. Take two or three features and chain them into one real task a non-technical viewer already does, such as handling a pile of messages, notes or a document. Analogy: a phone shortcut that runs five taps at once.
- Show: the task start to finish, with the spoken prompt on screen. Use "I'll come back" while the AI works, then "okay, it got done".
- Look for: time saved versus doing it by hand, and anything that went wrong. If a step failed, show the fix. That also breaks the "it takes too much time" belief.

[YOUR CALL: pick the workflow. Options: (a) a work task like emails or documents, good for business owners; (b) a content task, good for creators; (c) a personal task, the lowest barrier. Choose by who you most want watching.]

### Level 3: set it up once, reuse it (7:00 – 9:00)
- Say: the biggest hidden win is not a single trick. It's setting the tool up so it already knows you and your repeat jobs. Tie this to the "no AI employee working for me yet" problem. Analogy: training a new assistant once instead of explaining the job every morning.
- Show: build a small reusable setup live, as simple as the docs allow. Show it running on a fresh task to prove it carries over.
- Look for: does it work on the second run without extra explanation? If yes, say that is the point. If not, say what to tweak. Give the setup time and cost honestly.
