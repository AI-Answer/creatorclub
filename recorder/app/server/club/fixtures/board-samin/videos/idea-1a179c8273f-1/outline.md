## Points
**Sequence:** Before / shift / after for all three points. The illustration, framework and transition modes change in each one. Samin's roadmap habit is "three levels," so the three rounds are announced up front.

- Point 1: Round 1, drop the old habit and see the first difference
  - Setup: Say what the 2024 habit was and why people still do it. [CONFIRM: old habit #1]
  - Structure: Old approach → turning point (the feature) → result → rule → application.
  - On screen: Samin runs the task the old way, then the new way with the feature he already uses, and shows both outputs side by side. [CONFIRM: feature #1 and that Samin uses it]
  - Analogy or example: A before-and-after everyday comparison, such as handwriting a letter versus using a template. Samin picks his own wording.
  - Framework: Decision rule: "If you're repeating yourself to Claude, there's a feature for that."
  - Payoff: The viewer sees that the new way is a small change, not a technical skill, and it breaks "I need to be super technical."
  - Transition: Contrast. That fixed one habit, but the next one costs more time.

- Point 2: Round 2, stop redoing work Claude can remember or reuse
  - Setup: Name the second habit and what it costs in time. [CONFIRM: old habit #2]
  - Structure: Old approach → turning point → result → rule → application.
  - On screen: Samin repeats the same task, first the old way and then the new way, and shows the steps saved. [CONFIRM: feature #2 and that Samin uses it]
  - Analogy or example: A concrete scenario, such as a beginner coming back to Claude on Monday and starting from zero. Label it hypothetical.
  - Framework: Checklist: "Did I explain this before? Can Claude keep it? Then set it once."
  - Payoff: It answers "it takes too much time" with a visible before and after.
  - Transition: Escalation. The first two rounds improved the prompt, but the biggest change is letting Claude do more of the work.

- Point 3: Round 3, hand over the bigger job
  - Setup: Show the habit of doing every step by hand. [CONFIRM: old habit #3]

  - On screen: Samin runs the full task the old way, then again with the feature he uses most, and shows the finished results next to each other. [CONFIRM: feature #3 and that Samin uses it]

  - Framework: Loop: "Ask, check, adjust" replaces "retype, retry, give up."
  - Payoff: The viewer sees how the whole task changes and what to try first.
  - Transition: Callback to the hook. Show the old and new results from all three rounds on one screen.
