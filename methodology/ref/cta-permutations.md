# CTA Permutations

Choose the action from the user's real conversion goal, then choose a framing that fits the viewer's readiness.

## Actions

| Goal | Clear action |
|---|---|
| Conversation | Comment a word, answer a question, or reply |
| Retention | Save, share, or watch the next video |
| Audience | Follow or subscribe for a specific future value |
| Lead | Download, join, register, or send a message |
| Evaluation | View details, compare, start a trial, or attend a demo |
| Conversion | Buy, book, apply, or enroll |

## Framing permutations

- Value-first: benefit → action.
- Callback: hook/framework callback → action.
- Continuation: next problem → next asset/video → action.
- Challenge: small task → report back → action.
- Identity: relevant audience identity → action.
- Diagnostic: self-assessment → resource → action.
- Direct: action → location → benefit.
- Permission-based: qualify interest → low-pressure action.

## CTA formulas

- “If you want [specific outcome], [action] [location] and you'll get [truthful value].”
- “Use [framework] on [task], then [action] with [specific response].”
- “The next problem is [problem]. [Action] for [next solution].”
- “Before you [high-risk action], [low-friction action] to [benefit].”
- “[Audience], [action] if [qualification].”
- “Try [small task] today, then [action] and tell me [specific result].”

## Rules

- Use one primary action.
- Prefer a concrete verb over “check it out.”
- State what is on the other side of the action.
- Match ask size to trust earned.
- Do not manufacture urgency, scarcity, social proof, or guarantees.
- Avoid “like, comment, subscribe, and share” bundles.
- Remove “if you don't mind,” “maybe,” and apology language.
