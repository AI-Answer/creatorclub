# Setup Permutations

Select a small combination; do not stack every component.

## Setup modes

| Mode | Shape | Best for |
|---|---|---|
| Promise | callback → outcome → bridge | Fast educational videos |
| Stakes | problem → consequence → promised fix | Urgent pains |
| Proof | result → relevant method → bridge | Credible case studies |
| Story | moment → tension → lesson promise | Personal narratives |
| Roadmap | outcome → 2–3 beats → first beat | Complex teaching |
| Contrarian | accepted belief → correction → proof promise | Myth-busting |
| Diagnostic | symptom → hidden cause → test | Problem-solving |
| Challenge | constraint → attempt → result promise | Experiments |

## Element permutations

- Relevance: audience callout, shared situation, symptom, aspiration, or misconception.
- Promise: result, understanding, decision, skill, avoided mistake, or transformation.
- Stakes: lost time, money, effort, trust, opportunity, or momentum.
- Credibility: firsthand result, transparent method, sourced evidence, visible demonstration, or none.
- Roadmap: number of points, phases, escalating lessons, test, or before/after.
- Bridge: question, contrast, sequence, open loop, or direct first step.

## Transition starters

Adapt these; do not use them mechanically.

- “The first mistake happens before…”
- “To see why, start with…”
- “That sounds simple, but the mechanism is…”
- “Before the tactic, you need the rule…”
- “The result depends on one decision…”
- “This is where most people lose the plot…”

## Retention audit

- Does the setup answer “why should I keep watching?”
- Does it add information instead of repeating the hook?
- Is the promised payoff concrete and reachable?
- Is every credibility claim supportable?
- Does the final sentence make point one feel inevitable?
