# Hook Pattern Library

Use this library to select patterns; do not dump it into the final response. Prefer receipt, contrarian, or stolen-lesson patterns when the user has truthful specifics that support them.

## Category selector

| Available angle | Best starting category |
|---|---|
| Result, number, or experiment | Receipt |
| Strong opinion or wedge | Contrarian / myth-buster |
| Common mistake or risk | Negative frame |
| Copied tactic with attribution | Stolen lesson |
| Unanswered question | Curiosity gap |
| Multi-step how-to | Listicle / number |
| Real insider knowledge | Secret / insider |
| Narrow audience | Audience callout |
| Reflective question | Question |
| Change over time | Transformation / story |
| Fast or low-friction win | Speed / effortless |
| Genuine time sensitivity | Urgency / FOMO |
| Honest admission | Confession / vulnerable |

## Quality rules

- Specific beats abstract.
- Lead with the strongest number, name, surprise, or tension.
- Make the hook understandable on its own.
- Cut filler such as “really,” “very,” “just,” “actually,” and “basically.”
- Never use generic openings such as “In today's fast-paced world,” “Let me tell you,” or “Are you ready to.”
- Keep one hook to one idea.
- Do not imply private access, expertise, proof, or consensus the user does not have.
- Avoid precise percentages unless the user supplies a trustworthy source.
